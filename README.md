## Projekt - Generator Haseł
## Opis projektu
Aplikacja desktopowa stworzona w języku C# z wykorzystaniem Windows Forms. Umożliwia generowanie losowych haseł na podstawie wybranych przez użytkownika kryteriów. Dodatkowo ocenia siłę wygenerowanego hasła i pozwala na zapisanie go do pliku tekstowego.

## Funkcjonalności
Generowanie losowych haseł z możliwością wyboru:

małych liter

dużych liter

cyfr

znaków specjalnych

Ustawienie długości hasła (od 4 do 32 znaków)

Ocena siły hasła na podstawie długości i różnorodności znaków

Zapis wygenerowanego hasła do pliku `hasla.txt` z datą i godziną


## Technologie
Język programowania: C#

Środowisko: Visual Studio

Framework: .NET Framework 4.7 lub nowszy

Interfejs użytkownika: Windows Forms


## Uruchomienie aplikacji
Sklonuj repozytorium lub pobierz pliki projektu.

Otwórz projekt w Visual Studio.

Upewnij się, że masz zainstalowany .NET Framework 4.7 lub nowszy.

Zbuduj projekt `(Ctrl + Shift + B)`.

Uruchom aplikację `(F5)`.

## Zapis haseł
Wygenerowane hasła są zapisywane w pliku `hasla.txt`, który znajduje się w folderze:

```
[folder_projektu]/bin/Debug/
```
Każde hasło jest zapisywane z datą i godziną jego wygenerowania.
